# Перенос аккаунтов через Google Drive

В настройках Codex Accounts доступны сохранение и загрузка зашифрованного архива аккаунтов. Это ручной перенос через файл; приложение не подключается к Google API и не хранит пароль от Google.

1. Сохраните актуальные входы в профили приложения. Для пустых профилей сначала сохраните вход или удалите их.
2. В настройках введите мастер-пароль от 12 символов и повторите его.
3. Нажмите **Сохранить в Google Drive** и выберите синхронизируемую папку Google Drive для компьютера. Можно выбрать обычную папку и затем вручную загрузить файл на https://drive.google.com.
4. Дождитесь завершения загрузки файла клиентом Google Drive.
5. На новом устройстве установите Codex Accounts, выберите Codex Home, скачайте архив из своего Google Drive, введите мастер-пароль и нажмите **Загрузить из Google Drive**. Выберите файл `.encrypted`.

Каждое сохранение создаёт отдельный файл с датой и уникальным идентификатором. Импорт добавляет новые профили; повторный импорт создаёт копии. Текущий вход Codex и существующие профили не заменяются. На Ubuntu архив можно скачивать и загружать через браузер.

В архив входят названия профилей и сохранённые данные авторизации. История чатов, проекты, настройки и ключи системного хранилища не переносятся. После импорта входы защищаются локальным хранилищем Windows или Ubuntu. Устаревший либо отозванный вход потребует повторной авторизации. Одновременную работу копий одной сессии на разных устройствах нужно проверить отдельно.

Формат CAAR1: PBKDF2-HMAC-SHA256 (600 000 итераций, случайная соль 16 байт), AES-256-GCM (случайный nonce 12 байт, tag 16 байт); заголовок аутентифицируется. Пароль не сохраняется и не отправляется в Google Drive. Без пароля архив не восстановить. Архив вместе с паролем даёт доступ к сохранённым входам. Не добавляйте архивы в Git или публичные ссылки.

Успешное сохранение подтверждает запись локального файла, а не завершение синхронизации Google Drive. Автоматической синхронизации и объединения обновлённых токенов в этой версии нет.
